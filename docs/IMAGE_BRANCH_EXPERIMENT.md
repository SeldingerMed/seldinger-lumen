# One decision at a procedural fork

From the repository root, run `bash tools/image_navigation.sh`. It needs Bash, uv, and a supported CPU build of Warp. The first run installs Python 3.12 and the packages in `uv.lock`. No weights, GPU, service or patient data are needed. Each run creates a new directory and prints its path. Open `report.html` in a browser. To check the same bytes against a fresh execution on the same runtime, run `bash tools/image_navigation.sh --verify path/to/certificate.json`.

**What the policy knows:** its instruction is always “enter the selectively contrasted daughter.” It receives a single 64 by 64 grayscale detector image. It compares distal left- and right-sided contrast, chooses one of two insertion pulses, or stops. After that decision the pulse is open-loop. The simulator always uses the same left-oriented wire/rail setup for a given fork, not a rail chosen from the requested daughter. The evaluator knows the target edge, tip positions, and wall samples; the policy does not. The pulse-to-branch relationship is a property of these frozen setups, not a general steering law.

**Reading a replay:** reveal each case only after inspecting its image. A reach requires the measured tip on the requested edge at least 10 mm past the junction. The independent contact stop uses the maximum sampled penetration across the wire, not just at the tip, above 0.3 mm. Peak native wall load is in simulator units, not real force or an injury threshold. An abstention issues no motion. A reached case can still have nonzero wall interaction. The JSON certificate records every executed control, sampled edge, penetration and load. No learned controller is evaluated.

## Trajectory lineage is a separate question

`replacement-audit.json` comes from six other procedural CPU rollouts. Four development bases supply 44 training transitions; two held-out bases have distinct geometry parameters, seeds and action schedules. Per base, clean observations, three deterministic observation offsets and an exact copy give five records, not five independent experiments. Dev/test duplicates serve as positive controls for the detector, not independent evaluation. The audit checks all pairs, groups connected records, reports metrics separately by held-out base and degradation, and suppresses held-out metrics when lineages cross. A negative relative change means persistence won. This is a state-prediction baseline, not the image policy.

The three historical traces named by [issue 138](https://github.com/SeldingerMed/seldinger-lumen/issues/138) are not distributed in this checkout. Its headline MSE reduction must not be inferred from this experiment. Trial labels are not evidence of distinct trajectories. The historical file-hash and unchanged-baseline receipt is retained separately from the public replacement corpus.
